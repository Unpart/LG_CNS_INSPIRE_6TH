## 교육과정

### 1. Frontend

- HTML을 활용한 웹 문서 구조 설계
- CSS 및 Bootstrap을 활용한 화면 구성
- JavaScript 기본 문법과 DOM 이벤트 처리
- 비동기 처리: `Promise`, `async/await`
- React 컴포넌트 기반 UI 개발

### 2. Backend I

- Java 기본 문법과 객체지향 프로그래밍
- 캡슐화, 상속, 다형성, 추상화
- 컬렉션과 Stream API를 활용한 데이터 처리
- 관계형 데이터베이스 설계
- SQL 조회, 조인, 집계 및 트랜잭션

### 3. Backend II

- Spring Boot 기반 웹 애플리케이션 개발
- Controller, Service, Repository 계층 분리
- JPA를 활용한 데이터 영속성 관리
- REST API 설계 및 Swagger 문서화
- Spring Security 기반 인증·인가

### 4. Generative AI & REST API

- LLM과 생성형 AI의 기본 개념
- 프롬프트 작성 및 응답 비교
- 생성형 AI를 활용한 코드 리뷰와 오류 분석
- REST API 개발 및 코드 품질 개선
- AI 활용 과정과 결과 문서화

### 5. MSA & Cloud

- 모놀리식 아키텍처와 MSA 비교
- Docker 이미지 및 컨테이너 관리
- Dockerfile과 YAML을 활용한 환경 구성
- Kubernetes 기반 컨테이너 오케스트레이션
- EKS를 활용한 클라우드 배포

### 6. Project

- 미니 프로젝트 1: 학습한 프론트엔드·백엔드 기술 적용
- 미니 프로젝트 2: MSA 및 배포 경험 확장
- 해커톤: 제한된 시간 안에 아이디어 구현
- 최종 프로젝트: 실전 AM 서비스 설계, 개발, 배포 및 발표
